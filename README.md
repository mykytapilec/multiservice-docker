# Multiservice Docker

A containerized multi-service application built with Docker, Docker Compose, React, Node.js, MongoDB, Redis, and Nginx.

## Project Overview

This project demonstrates how to build, configure, and orchestrate multiple services using Docker.

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: MongoDB
- Cache: Redis
- Reverse Proxy: Nginx
- Containerization: Docker, Docker Compose
